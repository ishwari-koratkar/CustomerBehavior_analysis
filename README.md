# 📊 Customer Shopping Behavior Data Analytics

## 📌 Project Overview

This project is an **end-to-end Data Analytics project** based on customer shopping behavior data. The main objective is to analyze customer purchasing patterns, understand customer segments, identify factors affecting purchases, and generate meaningful business insights.

The project covers the complete data analytics workflow using **Python, SQL, and Power BI**, starting from raw data preparation and ending with an interactive dashboard and business insights.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze customer shopping behavior
- Clean and prepare the raw dataset
- Perform Exploratory Data Analysis (EDA)
- Identify customer purchasing patterns
- Analyze customer segments and preferences
- Use SQL to answer business questions
- Create an interactive Power BI dashboard
- Generate meaningful business insights
- Present findings in a simple and understandable way

## 🔄 Project Workflow

The project follows these major steps:

**Raw Dataset → Data Cleaning → Exploratory Data Analysis → SQL Analysis → Power BI Dashboard → Business Insights**

### 1. Data Collection

The project uses a customer shopping behavior dataset containing information related to customer purchases and shopping patterns.

The dataset includes information such as:

- Customer information
- Age
- Gender
- Item purchased
- Category
- Purchase amount
- Location
- Season
- Review rating
- Subscription status
- Discount information
- Previous purchases
- Payment method
- Frequency of purchases

---

### 2. Data Cleaning & Preparation – Python

Python was used to prepare the dataset for analysis.

The following activities were performed:

- Imported the dataset using Pandas
- Checked the dataset structure
- Checked missing values
- Checked duplicate records
- Checked data types
- Cleaned and transformed required columns
- Created useful features for analysis
- Prepared the final dataset for SQL analysis

---

### 3. Exploratory Data Analysis

Exploratory Data Analysis was performed to understand the dataset and identify important patterns.

The analysis focused on:

- Customer demographics
- Purchase behavior
- Product categories
- Customer spending
- Subscription behavior
- Review ratings
- Payment methods
- Purchase frequency
- Seasonal shopping patterns

Python libraries such as **Pandas, NumPy, Matplotlib** were used for analysis and visualization.

---

### 4. SQL Analysis

The cleaned dataset was loaded into a SQL database for further analysis.

SQL queries were used to answer business-related questions such as:

- Which products/categories are purchased the most?
- Which customer groups spend more?
- How does subscription status affect purchasing behavior?
- Which locations have higher customer activity?
- What are the popular payment methods?
- How does purchase frequency vary between customers?
- What factors are associated with higher spending?
- Which customer segments show stronger purchasing behavior?

---

### 5. Power BI Dashboard

The analyzed data was connected to **Power BI** to create an interactive dashboard.

The dashboard provides a visual overview of:

- 👥 Customer demographics
- 🛍️ Product categories
- 💰 Purchase amount
- ⭐ Customer ratings
- 🔄 Purchase frequency
- 💳 Payment methods
- 📍 Customer locations
- 🎯 Subscription behavior
- 📅 Seasonal trends

The dashboard helps convert the analyzed data into an easy-to-understand visual format.

---

## 📊 Key Insights

The project helps identify important patterns in customer shopping behavior, including:

- Customer purchasing patterns across different categories
- Differences in spending behavior among customer groups
- Relationship between subscriptions and purchasing activity
- Popular payment methods
- Customer preferences across locations
- Product and category performance
- Seasonal purchasing trends

These insights can help businesses understand their customers and improve their marketing and sales strategies.
